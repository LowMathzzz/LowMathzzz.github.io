Proyectos

Trabajo reciente

AAS-NET

CRM para corredores de seguros · Arias y Arias Corredores de Seguros

  • Software Engineer
  • Dic 2025 — Sep 2026
  • Remoto, a veces presencial
  • Entregado

Sistema que centraliza la operación de la corredora: pólizas, cuotas y vencimientos, siniestros, clientes, subagentes y reportes exportables. Lo desarrollé de punta a punta, desde el modelo de datos hasta la entrega.

  • Backend monolítico con la lógica de negocio, la API REST y el modelo de datos de toda la cartera.
  • Autenticación con JWT y estándares de hardening en la API.
  • Roles y permisos para subagentes, administrativos y gerentes.
  • Cifrado de la base de datos y refuerzo de la seguridad del frontend.
  • Trabajo remoto, coordinando con el equipo en sitio cuando fue necesario.

API REST · JWT · Control de acceso por roles · Cifrado de datos · Hardening · Reportes

DoxaCore

Gestión operativa para restaurantes y parrillas

  • Diseño y desarrollo completo
  • 2025 — actualidad
  • Proyecto personal
  • En desarrollo

Plataforma web modular para la operación diaria de un restaurante: asistencia y planilla, gastos y cuentas por pagar, conciliación de ventas, inventarios con recetas y recepción de productos.

  • Procesamiento automático de archivos Excel: biométrico, reportes de ventas y pedidos de proveedores.
  • Cálculo de tardanzas, descuentos y sueldos a partir de esos datos.
  • Cifrado de datos sensibles y control de acceso por roles.
  • Sesiones con expiración y protección contra abuso.

Python · Flask · MySQL · pandas · Jinja2 · Chart.js
