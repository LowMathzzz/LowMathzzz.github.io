Sobre mí

▼ 0 cm

Construyo backends seguros y escalables con Java y Spring Boot, y apps multiplataforma con Flutter.

Me apasiona la seguridad de las APIs: autenticación con JWT, control de acceso por roles, cifrado de datos y hardening. Diseño con arquitectura hexagonal y Clean Architecture para que el dominio nunca dependa del framework, y uso Kafka cuando los servicios necesitan hablar por eventos sin acoplarse.

Llevo el código a producción con Docker y pipelines de CI/CD en GitHub Actions y Jenkins, probado con JUnit y Mockito, sobre AWS y Azure y con Grafana para ver en vivo qué pasa. Estudio Ingeniería de Software en la UPC (Lima) y me formo como Backend Developer.

01Arias y Arias Corredores de SegurosEntregado

AAS-NET

CRM para corredores de seguros

  • Software Engineer
  • Dic 2025 — Sep 2026
  • Remoto, a veces presencial

Plataforma que concentra toda la operación de la corredora en un solo sistema: pólizas, cuotas y vencimientos, siniestros, clientes, subagentes y reportes exportables. La construí de punta a punta: modelo de datos, API, seguridad, despliegue y entrega.

  • Backend modular en Spring Boot 3 y Java 21, con API REST documentada en OpenAPI y modelo de datos en PostgreSQL para toda la cartera.
  • Autenticación stateless con Spring Security y JWT, y hardening de la API: validación de entrada, rate limiting y cabeceras seguras.
  • Control de acceso por roles (RBAC) para subagentes, administrativos y gerentes, aplicado en cada endpoint.
  • Cifrado de datos sensibles en reposo y refuerzo de la seguridad del frontend para proteger clientes y pólizas.
  • Contenedores Docker y pipeline de CI/CD en GitHub Actions; trabajo remoto coordinado con el equipo en sitio.
  • Java 21

02Proyecto personalEn desarrollo

DoxaCore

Gestión operativa para restaurantes y parrillas

  • Diseño y desarrollo completo
  • 2025 — actualidad

Plataforma SaaS modular para la operación diaria de restaurantes y parrillas: asistencia y planilla, gastos y cuentas por pagar, conciliación de ventas, inventario por recetas y recepción de mercadería, todo desde un solo panel.

  • Ingesta automática de archivos Excel (marcaciones biométricas, reportes de ventas y pedidos de proveedores) con Apache POI y procesamiento asíncrono.
  • Motor de cálculo de tardanzas, descuentos y sueldos a partir de esos datos, sin planillas manuales.
  • Frontend en React y TypeScript con dashboards de ventas, costos y personal.
  • Cifrado de datos sensibles y control de acceso por roles con Spring Security.
  • Sesiones con expiración en Redis y rate limiting contra abuso; desplegado con Docker en AWS.
